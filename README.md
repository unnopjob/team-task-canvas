# 📌 Team Task Canvas

ระบบกระดานโพสต์อิทงานทีมแบบ Realtime (Kanban & Freeform Canvas)

## ✨ คุณสมบัติเด่น
- 📋 **คอลัมน์ Kanban:** จัดหมวดหมู่สถานะงาน (ต้องทำ, กำลังทำ, รอตรวจ, เสร็จสิ้น) พร้อมระบบลากวาง (Drag & Drop)
- 🎨 **กระดานอิสระ (Canva):** ดับเบิลคลิกแปะโน้ตและลากวางอิสระเหมือนไวท์บอร์ดจริง
- 🏷️ **ระบบแท็กงานอัตโนมัติ (#Hashtag):**
  - `📋 #ใบเสนอราคา` / `#QT`
  - `📄 #เอกสาร`
  - `🧪 #POC`
  - `🤝 #ลูกค้า`
  - `📦 #PO`
  - `🔥 #ด่วน`
- ⚡ **เข้าใช้งานทันที (Guest Mode):** ระบุชื่อเล่นและเลือกสีประจำตัวได้ทันทีโดยไม่ต้องเชื่อมต่อระบบที่ซับซ้อน
- 🔄 **Realtime Database:** รองรับการเชื่อมต่อ Firebase ซิงค์ข้อมูลข้ามเครื่องแบบสดๆ
